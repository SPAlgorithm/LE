# Uploading the two videos to YouTube

Before you start: a channel can only upload videos longer than 15 minutes after it is
verified (Settings > Channel > Feature eligibility > "Intermediate features", phone code).
Video 1 is 28 minutes, so do this first if the channel is new.

For each video (Video 1 first, then Video 2):

1. studio.youtube.com > Create > Upload videos > choose the MP4 listed in
   `video1_youtube.txt` / `video2_youtube.txt`.
2. Details: paste the TITLE and DESCRIPTION from the txt file. Upload the THUMBNAIL.
   Playlist: create "Ladhe's Quad Conjecture" on the first upload, add the second to it.
   Audience: "No, it's not made for kids".
3. Show more: Tags (paste the TAGS line), Category "Education", Video language "English",
   License "Standard YouTube License", leave "Allow embedding" on.
4. Video elements: Subtitles > Add > Upload file > choose the transcript .txt
   ("Without timing"): YouTube syncs it to the audio and gives clean captions on top of
   the burned-in ones. End screen: add the other video (do this after both are uploaded).
5. Checks: wait for the copyright check (there is no music, so it passes).
6. Visibility: Private for now. Save. Copy the link (Share) and send both links to me.

After both are uploaded:
- Edit each description and replace "[paste the Video 2 link here]" / "[paste the Video 1
  link here]" with the real links; add the end-screen links.
- Done on 2026-09-03: Video 1 https://youtu.be/_XSOJ0Yj77Q, Video 2 https://youtu.be/JNWvt3hS540 (recorded in the paper, LINKS.md and the README).
- When you switch Private -> Public later, the links stay the same.

Chapters only appear if the description keeps the "00:00" line first and the timestamps in
increasing order, which the txt files already do.
